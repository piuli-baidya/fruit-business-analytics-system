# Fruit Business Analytics System

A data-driven analytics system for small-scale fruit business operations.

## Problem

My father operates a fruit business. Inventory and purchasing decisions are made primarily from experience. Spoilage and demand fluctuations create uncertainty, but no structured data exists to evaluate performance.

## Goal

Build a Python-based analytics system that tracks inventory, profitability, and spoilage patterns to support better business decisions.

## Current Status

Project in progress.

Data collection and system development are underway.

## Planned Analysis

The system will analyze:

- Profit and loss
- Revenue and cost
- Fruit-level performance
- Spoilage rates
- Potential demand patterns
- Inventory risk

## Technology

- Python
- pandas
- CSV

## Future Development

If the collected data supports it, the project may later include inventory decision-support features such as reorder thresholds and safety-stock analysis.
